## Methods

| Method | Stage 1 (top-K) | Stage 2 |
|---|---|---|
| Hop-count | hop count, K = 1 | – |
| Latency | measured LLDP delay, K = 1 | – |
| Bandwidth (widest) | max-bottleneck available bandwidth, K = 1 | – |
| Baseline: hop-count + ML | hop count, K = 5 | probe all 5, soft-voting ensemble, lowest class |
| Ours: combined + ML | composite α·D + β·J + γ/BW + δ·L, K = 5 | probe all 5, soft-voting ensemble, lowest class (ties: composite cost) |

Each topology uses its own ensemble (XGBoost, Random Forest, Gradient Boosting, SVM; soft vote), trained on that topology's dataset. Stage 2 predicts all K candidates in one batched call.
